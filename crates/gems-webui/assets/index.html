First-run setup

Seeds the admin/analyst/consumer roles, a starter policy set, and one admin user, then mints that user's access token. Run this once per cluster (also available as gems-cluster-node install from the command line). Requires this server's $GEMS_WEBUI_SECRET — proving you already have some other way into the deployment, not just network access to it.
